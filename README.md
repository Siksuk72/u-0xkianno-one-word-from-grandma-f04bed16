One word from grandma: **robit**.

It reads exactly as a grandma would text about AI — "robit" is the typo
she would actually make. Warm, a little baffled, and funny in a single
word with no caption needed. It is tied to robots and AI rather than
any other subject, and it is fresh: not the obvious "robot", not a
generic endearment like "dearie". Five characters, one word, straight
through the gate.

## Run it

```bash
python3 main.py
```

This writes `robit` to `/output/entry.txt` (UTF-8, no trailing newline).
